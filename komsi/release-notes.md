**K-OMSI** - [openOMSI](https://github.com/openOMSI-Project/openOMSI) 0.2.27을 바탕으로 K-OMSI 수정을 얹은 빌드입니다.

> **초기 단계 프로젝트입니다. 버그가 있을 수 있습니다.** OMSI 2 정품이 설치되어 있어야 실행됩니다. 이 프로그램에는 게임 콘텐츠가 들어 있지 않습니다.

## K-OMSI에서 더한 것

- **표시 이름**: 창 제목과 업데이트 안내가 K-OMSI로 표시됩니다. 자동 업데이트는 공식 openOMSI가 아니라 이 저장소의 릴리스를 확인합니다.

이전 릴리스에 있던 시간표 버스 보정, HTML 한글 폰트, 출발 정보 표시, 차고지 행선 문구는 공식 openOMSI에 반영되어 이번부터 별도 패치가 필요 없습니다. 가로등 그림자 보정 패치는 이번에 뺐습니다.

## openOMSI 0.2.22 ~ 0.2.27 공식 변경사항 (요약)

### 새 기능
- **환경음 (0.2.27)**: 실제 녹음 기반의 환경음 (장소, 계절·시간대 자연음, 날씨, 도시 소리). 설정 → 소리 → 환경음에서 켜고 끌 수 있으며, 처음 켤 때 녹음 파일(약 300MB)을 한 번 내려받습니다. 안드로이드는 아직 미지원
- **모드 페이지 (0.2.27)**: 모드가 담고 있는 폴더·항목을 펼쳐서 확인
- **사진 모드 (0.2.26)**: 일시정지 메뉴에서 실제 렌즈 설정, 심도, 롤링샷, 보정, 프레임 등을 갖춘 자유 카메라로 촬영
- **일시정지 메뉴 (0.2.26)**: 런처와 같은 모양으로 변경
- **승객 애니메이션 옵션 (0.2.26)**: 절차적 애니메이션을 선택 가능 (기본값은 원래 OMSI 방식)
- **구름량 슬라이더 (0.2.26)**: 구름이 하늘을 덮는 정도를 연속적으로 조절
- **비 품질 설정 (0.2.24)**: 그래픽 → 비 품질 (높음/중간/낮음)
- **트램 (0.2.24)**: 여러 량 편성 트램의 궤도 추종, 편성 로드 개선, 씬 오브젝트의 스위치·버튼 클릭
- **HTML 페이지 확장 (0.2.24)**: 도착까지 남은 정류장, 혼잡도, 지연, 막차 여부, 날씨, 차고지 행선 문구, 한글·한자·가나 폰트 대체
- **플러그인 (0.2.22)**: Lua API 확대, 플러그인 패널 위젯, WebAssembly·컴파일(.oop) 플러그인
- **AI 교통 개선 (0.2.22)**: 정체와 교착 감소
- **Vanilla/Vanilla+ 하늘 (0.2.22)**: Omsi.exe와 같은 하늘 표현

### 수정
- 마우스 조향 중 시점 조작이 부드러워지고, 인터페이스 구분 기호가 단순해짐 (0.2.26)
- DirectX 11(ANGLE) 그리기, DirectX 12 눈 표현 복구, 차량 반사가 조명을 따라가도록 수정 (0.2.26)
- 바람에 흔들리던 표지판·가로등·신호등·울타리가 흔들리지 않음 (0.2.27)
- 신호등 없는 교차로에서 AI 차량이 서로 기다리며 멈추던 문제 수정 (0.2.27)
- 행선지 표시기에 변형 여러 개가 겹쳐 보이던 문제, LED 행선판이 어두운 문제, 표시 전환 중 행선 선택 문제 수정 (0.2.25/0.2.26)
- 주행 중 눈 날씨로 바꿔도 지면이 덮이도록 수정 (0.2.25)
- 짧은 도로 조각으로 이어진 교차로에서 AI 차량이 되돌아 막히던 문제 수정 (0.2.25)
- 스플라인을 따라 놓이는 오브젝트의 위치, 씬 텍스처 차용 문제 수정 (0.2.24)
- 환경음이 지직거리던 문제 수정 (0.2.23), 태양 그림자 떨림·무늬 개선 (0.2.22)

공식 변경 내역 전문(영어): [CHANGELOG](https://github.com/openOMSI-Project/openOMSI/blob/main/CHANGELOG.md)

## 다운로드

| 플랫폼 | 파일 |
| --- | --- |
| Windows x64 | `openOMSI-<버전>-windows-x64.zip` (`openomsi.exe` 실행) |
| Windows ARM64 | `openOMSI-<버전>-windows-arm64.zip` |
| macOS (Apple silicon / Intel) | `-macos-arm64.zip` / `-macos-x64.zip` |
| Linux x64 / ARM64 | `-linux-x64.zip` / `-linux-arm64.zip` |
| Android (arm64, 8.0+) | `-android-arm64.apk` |
| 전용 서버 | `-server-linux-x64.zip`, `-server-linux-arm64.zip`, `-server-windows-x64.zip`, `-server-windows-arm64.zip` |

> 파일 이름이 `openOMSI-…`로 되어 있는 것은 자동 업데이트가 이 이름 형식으로 파일을 찾기 때문입니다.
