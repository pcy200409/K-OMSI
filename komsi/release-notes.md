**K-OMSI** - [openOMSI](https://github.com/openOMSI-Project/openOMSI) 0.2.48을 바탕으로 K-OMSI 수정을 얹은 빌드입니다.

> **초기 단계 프로젝트입니다. 버그가 있을 수 있습니다.** OMSI 2 정품이 설치되어 있어야 실행됩니다. 이 프로그램에는 게임 콘텐츠가 들어 있지 않습니다.

## K-OMSI에서 더한 것

- **표시 이름**: 게임 창 제목이 K-OMSI로 표시됩니다. 자동 업데이트는 공식 openOMSI가 아니라 이 저장소의 릴리스를 확인합니다.
- **텔레메트리 페달·주행거리**: 텔레메트리의 플레이어 항목에 가속·브레이크·클러치 페달 값(0~1, 운전석과 같이 컨트롤러 입력이 키보드보다 우선)과 버스 총 주행거리(`odometer_km`)를 더했습니다. 외부 채점 도구(DTG / light-taco 등)용입니다.
- **승객 좌석 선택**: 승객이 빈자리를 무작위로 잡지 않고 고릅니다. 짧게 타는 승객은 하차문 근처에 서고, 멀리 가는 승객은 안쪽에 앉으며, 남은 몇 자리는 멀리 가는 승객 몫입니다. 노인(65세 이상)은 빈 좌석이 있으면 앉고 탄 문 가까이 앉습니다. 빈 2인석·창가·사람과 떨어진 입석 자리를 먼저 고릅니다.
- **LAN 차량번호·번호판**: 멀티플레이에서 다른 플레이어의 버스가 그 플레이어 화면과 같은 차량번호와 번호판으로 보입니다.
- **AI 차량 차선 변경 신호**: AI 차량이 다른 차선으로 옮기기 2초 전에 방향지시등을 켭니다(기존 1.2초).
- **NVIDIA DLSS / DLAA (시험 기능)**: 설정 → 그래픽 → 안티에일리어싱 아래 **DLSS** 칸(끔·DLAA·품질·균형·성능·울트라 성능). 기본은 꺼짐입니다. Windows + DirectX 12(켜면 자동 선택) + GeForce RTX가 필요하고, NVIDIA Streamline의 `sl.interposer.dll`, `sl.common.dll`, `sl.dlss.dll`, `nvngx_dlss.dll`을 [Streamline SDK](https://github.com/NVIDIA-RTX/Streamline) `bin/x64`에서 받아 `openomsi.exe` 옆에 넣어야 합니다(NVIDIA 파일은 포함하지 않음). 없으면 이유를 로그에 남기고 평소대로 그립니다. openOMSI PR #942(Nussaccino)를 옮겨 온 것입니다.
- **ReShade 호환**: 게임이 ReShade를 넣으면 창이 뜨기 전에 꺼지던 문제를 고쳤습니다(wgpu의 `IDXGIFactoryMedia` 생성 제거, Criisko/openOMSI 방식). ReShade는 `openomsi.exe`에 DirectX 10/11/12로 설치하세요. 두 방식 쓰는 법: [DLSS · ReShade 안내](https://github.com/pcy200409/K-OMSI/blob/branding/komsi/RESHADE_DLSS.md)
- **HTML 페이지 한글 글꼴 지정**: `openomsi.exe` 옆 `fonts/html_fallback.ttf`(굵은 글씨는 `html_fallback_bold.ttf`)가 있으면 HTML 페이지(정류장 안내기, 단말기 화면 등)의 한글을 그 글꼴로 그립니다(없으면 기존대로 맑은 고딕). 업데이트해도 이 파일은 지워지지 않습니다.
- **지도 오브젝트 화면·글자·소리 누락 수정**: 늦게 불러온 타일의 스크립트 오브젝트 일부가 화면(HTML 페이지)·글자 텍스처·소리·움직임을 받지 못하던 문제를 고쳤습니다(정류장 버스정보안내기가 검게 나오던 원인). 공식 openOMSI에도 있는 문제입니다.
- **한국어 번역 보완**: 번역이 없던 인터페이스 문구 1,351개(런처, 설정, 날씨, 컨트롤러, LAN 등)를 기계 번역으로 채웠습니다. 어색한 표현은 이슈로 알려 주세요.


## openOMSI 0.2.48 공식 변경사항 (요약)

0.2.46 ~ 0.2.48 (0.2.47은 배포되지 않음)

> **온라인(멀티플레이)은 모든 컴퓨터가 0.2.48 이상이어야 합니다**(세션 프로토콜 6 → 7, 이전 버전은 접속 시 거부). 전용 서버의 `admin_password`는 8자 이상이어야 합니다.

### 새 기능
- **0.2.48**: 런처의 **모델 테스트** 페이지(모드 제작자용, 버스를 창 없이 운행과 똑같이 읽어 `.bus`·모델·메시·스크립트·constfile·도색의 경고·오류와 빠진 텍스처를 나열, `openomsi --check-vehicle`), 맵 패키지(`Maps/<맵>/openomsi-realmap`)가 있으면 내비게이터·도시 지도에 물·공원·숲·강·철도·경계를 그림(설정 "내비게이터 지면", "밝은 내비게이터" 추가), 런처가 창 크기에 맞춰 커지고 **런처 크기** 설정·**클래식 레이아웃**(버스 → 날짜·날씨 → 맵·근무 단계별 운행 페이지)·버스 미리보기를 승객석·운전석에서 보기, 운행 중 런처 쉬기
- **0.2.46**: 설정 "마우스로 페달 조작"(끄면 마우스 조향은 조향만)·"페달 키 속도", 라디오 키(다음/이전 방송국, 음량), 마우스 옆 단추(Mouse 4/5) 지정, "자유 카메라 키 켜기/끄기" 키, 승객의 말을 OMSI식 힌트로 표시, 설정 "동시 인원"(AI 사람 수 50~1000), 런처의 시작 날짜 달력·마우스 휠로 시각·날짜 조절·선택한 날짜에 없는 투어를 다음 날로 한 번에·맵 전체 노선의 다음 출발·투어에 시간표가 정한 버스 제시·맵과 버스에 개인 메모·R/N 키가 어느 변속기용인지 표시, 정보 표시줄에 도로 제한속도·하차 요청, 빠른 메뉴 행선지 입력에 차고 파일 행선지 제시, 터치 조작에 안내방송(Q) 단추, 스크린샷에 UI 제외, 업데이트·다운로드가 시스템 프록시 사용, 게임 메뉴에서 배치된 차량 중 운전할 차량 선택

### 수정
- **보안 강화** (0.2.48): 모드 압축 파일이 설치 중인 모드 밖에 쓰지 못함, 텍스처 등 콘텐츠 이름·다른 플레이어의 롤사인·스크립트 문자열이 다른 컴퓨터(`\\server\share`)나 콘텐츠 폴더 밖을 가리키지 못함, 온라인 세션의 호스트 서명(세션별 키)으로 사칭 방지·엿들은 접속 요청으로 자리 뺏기 방지·외부에 세션 노출 안 함, 전용 서버 관리자 로그인에 PBKDF2, 차단이 주소 기준으로 유지, 모드 다운로드·WebSocket 게이트웨이·엄청난 항목 수를 주장하는 파일로 메모리 고갈·멈춤 방지, 조작된 glTF·`.x`·TGA·zip으로 인한 충돌 방지, Android 업데이트 응답 위조 방지, 런처 glib(Linux, RUSTSEC-2024-0429)·플러그인 패키지 zstd 해제기 ruzstd 0.9.1(RUSTSEC-2026-0344) 보안 수정
- 로딩 화면이 다시 맵 그림 없는 어두운 배경(0.2.46에서 넣었던 것을 되돌림), 승객이 행선지를 IBIS에 설정된 차고 파일 줄에서 읽음, 문 하나가 열려 있으면 단추 달린 닫힌 문에서 기다리지 않음, 보도 없는 곳에서 내린 승객이 문 앞에 몰리지 않고 흩어짐, 맵의 기사 목록이 승객에 섞이지 않음, 도색 폴더에서는 `.cti`가 지정한 것만 가져옴, 도색의 `[setvar]`를 스크립트 매 프레임 전에 씀(Omsi.exe와 같게), Windows-1250 세르비아어·크로아티아어 문자, Mac 앱 덮어쓰기 문제, iPhone 터치 단추 위치, 의존성 업데이트 (0.2.48)
- **AI 교통** (0.2.46): 우선권을 주장하는 차량(일부 맵의 플레이어 버스, 사이렌 켠 긴급차) 근처에서 녹색 신호에 멈춰 서던 문제, 길 한가운데서 차가 사라지던 문제, 우선순위가 없는 교차로는 OMSI 2처럼 먼저 온 차가 먼저 감, 실선 중앙선(`overtaking_prohib`)을 넘지 않음, AI 항공기·열차가 젖은 길에 물보라를 일으키지 않음
- **운행·시간표** (0.2.46): 자정을 넘기는 야간 투어, 노선번호 없는 000 운행의 자동 IBIS, 걸어 다닐 때 내비게이터가 버스 기준 유지, 종점 도착 즉시 다음 운행 시작(OMSI 2처럼), AI 버스가 정류장에서 바짝 줄 서고 뒤 차도 동시에 승차, 첫 정류장에서 대기하는 시간표 버스의 문 열림, 지켜보는 중에도 종점 정시 출발, 문을 닫지 않는 스크립트의 AI 버스가 정류장에 영원히 서 있지 않음, 근무 기록에 버스별 주행거리(`[perbusinfo]`), `[depot]` 건물에서 급유·충전, LAN에서 AI 버스 도색이 모든 플레이어에게 같게, 다른 플레이어 굴절버스 뒷부분 기울기·바퀴
- **승객** (0.2.46): 보도 없는 곳에서 내린 뒤 버스를 떠남, 문이 열린 채인 버스에서도 하차벨을 제때 누름, 맵 정류장 설정대로 하차, 맵 기사 목록이 승객에 나오지 않음, 카메라 주변 정류장에서 승객 대기, 긴 정차 구역 앞쪽에 있는 정류장 처리
- **조작** (0.2.46): Ctrl·Alt 조합키가 게임 고유 Shift 단축키를 함께 실행하지 않음(keyboard.cfg 지정 우선), 지정된 Num+/Num-가 외부 카메라 확대를 하지 않음(새 "확대/축소" 키), Shift·Ctrl·Alt 단독 지정, 놀고 있는 게임패드가 핸들을 되돌리지 않음, 게임패드 조향이 고속에서 느리게 돌아감, 운전석 카메라 전환 시 확대가 부드럽게 따라감, 휠 사용 시 화살표 키가 기본으로 카메라 전환, 헤드트래킹이 매 프레임 부드럽게, 마우스 휠 확대가 스위치 위에서 멈추지 않음, 빠른 메뉴가 keyboard.cfg의 키를 따름
- **그래픽·소리** (0.2.46): AI 열차 등장 시 끊김 제거, 그래픽 메모리 부족 시 검은 화면 대신 텍스처를 단순하게 그림, 승객 아바타 그림을 미리 읽어 끊김 제거, 텍스처 압축이 작은 색 견본 색을 바꾸지 않음, 완전 투명 `[matl_alpha] 2` 메시가 뒤를 가림(Enhanced 포함), Enhanced 도색 광택이 유리처럼 번쩍이지 않음·전조등 빛이 경사에서 버스와 함께 기울어짐·라이트맵 패널 낮 밝기, Vanilla+ 밤·황혼·그늘이 OMSI 2만큼 어두움, 문 부딪힘 소리 끝까지 재생, 시야 밖으로 튄 AI 차량 엔진음 폭발 제거
- **기타** (0.2.46): 승차권 블록이 버스 변경 후 길 위에 떠 있지 않음, 거스름 동전 다시 클릭으로 집기, 런처 위치한 화면에서 게임 열림, "무작위 도색"이 실제로 무작위, 런처 버스 이름 전체 표시, Android 키 변경·휠 설정이 조작 페이지를 엶, Linux에서 런처 실행 불가 시 이유 안내(SteamOS), 게임 메뉴에서 좌석·시야 조정 시 뒤 화면 보임, 시간표 버스를 끈 자유 주행에서 노선·투어 다시 선택

## 다운로드

| 플랫폼 | 파일 |
| --- | --- |
| Windows x64 | `openOMSI-<버전>-windows-x64.zip` (`openomsi.exe` 실행) |
| Windows ARM64 | `openOMSI-<버전>-windows-arm64.zip` |
| macOS (Apple silicon / Intel) | `-macos-arm64.zip` / `-macos-x64.zip` |
| Linux x64 / ARM64 | `-linux-x64.zip` / `-linux-arm64.zip` |
| Android (arm64, 8.0+) | `-android-arm64.apk` |
| 전용 서버 | `-server-linux-x64.zip`, `-server-linux-arm64.zip`, `-server-windows-x64.zip`, `-server-windows-arm64.zip` |

> 파일 이름이 `openOMSI-…`로 되어 있는 것은 자동 업데이트가 이 이름 형식으로 파일을 찾기 때문입니다.
