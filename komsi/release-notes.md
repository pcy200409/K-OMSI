**K-OMSI** - [openOMSI](https://github.com/openOMSI-Project/openOMSI) 0.2.45를 바탕으로 K-OMSI 수정을 얹은 빌드입니다.

> **초기 단계 프로젝트입니다. 버그가 있을 수 있습니다.** OMSI 2 정품이 설치되어 있어야 실행됩니다. 이 프로그램에는 게임 콘텐츠가 들어 있지 않습니다.

## K-OMSI에서 더한 것

- **표시 이름**: 게임 창 제목이 K-OMSI로 표시됩니다. 자동 업데이트는 공식 openOMSI가 아니라 이 저장소의 릴리스를 확인합니다.
- **텔레메트리 페달·주행거리**: 텔레메트리의 플레이어 항목에 가속·브레이크·클러치 페달 값(0~1, 운전석과 같이 컨트롤러 입력이 키보드보다 우선)과 버스 총 주행거리(`odometer_km`)를 더했습니다. 외부 채점 도구(DTG / light-taco 등)용입니다.
- **승객 좌석 선택**: 승객이 빈자리를 무작위로 잡지 않고 고릅니다. 짧게 타는 승객은 하차문 근처에 서고, 멀리 가는 승객은 안쪽에 앉으며, 남은 몇 자리는 멀리 가는 승객 몫입니다. 노인(65세 이상)은 빈 좌석이 있으면 앉고 탄 문 가까이 앉습니다. 빈 2인석·창가·사람과 떨어진 입석 자리를 먼저 고릅니다.
- **LAN 차량번호·번호판**: 멀티플레이에서 다른 플레이어의 버스가 그 플레이어 화면과 같은 차량번호와 번호판으로 보입니다.
- **한국어 번역 보완**: 번역이 없던 인터페이스 문구 1,351개(런처, 설정, 날씨, 컨트롤러, LAN 등)를 기계 번역으로 채웠습니다. 어색한 표현은 이슈로 알려 주세요.


## openOMSI 0.2.45 공식 변경사항 (요약)

0.2.38 ~ 0.2.45 (0.2.40은 배포되지 않음)

### 새 기능
- **0.2.45**: 버스의 `[htmltexture]` 페이지에도 `lit` 지정 가능(햇빛·가로등·안개를 받는 면이 되어, 점 마스크와 흰 빛 지도를 쓰면 Enhanced에서 Krueger·K++ 패널처럼 점이 켜지는 LED 매트릭스가 됨), 번체 중국어 번역 보완, 런처의 "Light" 테마 이름 표기 정리
- **0.2.44**: 설정 → 게임플레이 → 승객의 "캐릭터 모델: 고품질(개선)"(Microsoft Rocketbox 아바타 91종으로 사람을 그림, 내 컴퓨터에서만), glTF/GLB·FBX·OBJ 모델 읽기, 거의 모든 그림 형식(DDS BC4~BC7, KTX, WebP, GIF, TIFF, EXR 등)과 소리 형식(AIFF, CAF, M4A, Matroska, MP2, 다양한 WAV 등) 지원
- **0.2.43**: 사진 모드 피사계 심도의 겹침(고스트) 제거와 클릭한 곳에 초점, 사진가용 고급 모드(센서 크기·실제 초점거리·P/A/S/M 노출·측광)와 간단 모드의 모션 고정·테두리·수평계, 승객의 자연스러운 자세가 기본값(설정에서 원본 OMSI 선택 가능), 단위(미터법/영국식/미국식), 시간 메뉴에 요일이 있는 날짜와 하루·주·달 이동, 스크립트 텍스처에 그리는 플러그인(단말기 모드용), 런처의 시간표 편집기·사용자 지정 날씨·IBIS 입력값 표시·라디오 방송국 편집 복원
- **0.2.42**: 거울 품질 "그림과 같이(Enhanced)"(Enhanced의 빛과 하늘로 거울을 그림)와 실시간 반사 "매 프레임"(거울을 매 프레임 다시 그려 속도에 따라 화면이 흔들리던 현상 제거), Enhanced·Enhanced+에서 AI 차량이 전조등으로 도로를 비춤
- **0.2.39**: 시뮬레이션이 모든 컴퓨터·프레임에서 초당 120스텝 고정(`OMSI_FIXED_STEP` 폐지), 데스크톱 런처가 유일한 런처(게임 자체 런처 삭제), 런처의 Discord 상태 복원, 일시정지 메뉴 첫 페이지에서 게임 화면이 흐리게 보임, Enhanced+ 반사에 실제 텍스처 적용, 노선·투어 선택 목록과 검색 복원, 스웨덴어 추가, 접속한 서버의 맵·시계·날씨·버스 설정, 모든 버스용 문 해제 동작(`doors_release`), 런처의 버전 선택 설치, HTML 텍스처의 `lit` 지정 등 (기여자 다수)
- **0.2.38**: 휠·페달·조이스틱 자동 설정(X축=조향, 끝에서 쉬는 축=페달, 결합 페달 장치는 Y축), 컨트롤러 페이지 개편, 실시간 성능 패널, Alt 빠른 메뉴 아이콘 타일화, 버스 선택기에서 모델별 한 줄, 현재 날씨(METAR)·날씨 주기 선택 복원, 시작 시각을 현재로 맞추는 버튼, 넓은 화면의 2열 운행 페이지, 프랑스어 알림 번역
- **성능**: 로딩 시 회전교차로 탐색 2~5배 빨라짐(0.2.38), 맵 데이터 스냅샷·무잠금 읽기 등 코어 재구성(0.2.39, `OMSI_SIM_THREAD=1`로 교통·승객·맵 스크립트를 별도 스레드로, 기본 꺼짐)

### 수정
- 버스가 빠르게 달릴 때 운전석 시점 앞에서 기사가 깜박이던 문제(거울과 사진 모드에서는 계속 보임), AI 버스가 가속·제동 소리를 냄(스크립트에 가속·브레이크 페달 전달), 건물 아래에서 걸어서 일어서면 지붕 위가 아니라 바닥에 서게 됨 (0.2.45)
- 120프레임 미만에서 프레임률 향상(시뮬레이션을 초당 60스텝, 프레임당 최대 4스텝으로), 8GB 그래픽카드에서 30분 뒤 프레임이 급락하던 문제, 자동 렌더 배율이 85~100%를 오가던 문제, Enhanced 야간 부하 감소(가까운 AI 차량 12대만 전조등), Apple M4 Mac에서 전체 화질로 다시 그려짐 (0.2.44)
- 움직이는 차량에 딸린 것(거울·등·승객·동전 등)이 떨리지 않음, 키 바인딩·컨트롤러 설정이 업데이트 후에도 유지(`~/.openomsi/Inputs`), 대소문자 구분 파일 시스템에서 `Maps` 폴더가 기본 맵을 가리지 않음, 승객 다리·좌석 앉기 동작, 정류장 벤치 앉기, Enhanced+ 그림자, 새해를 넘기는 시계, 지도 이동, 시작 지점 목록, .x 모델 텍스처 좌표 등 (0.2.43)
- Windows: WebView2 설치 안내가 런타임이 정말 없을 때만 나옴 (0.2.42)
- 태양이 실제 크기(0.27도)로 그려지고 눈부심이 카메라 회전에 따라 깜박이지 않음, 밤에도 도색·유리 반사 유지(Vanilla), Enhanced에서 차체에 래커 광택 (0.2.42)
- 사진 모드에서 운전석 카메라가 벗어나도 기사가 핸들에 앉아 있음 (0.2.42)
- 휴대폰의 화면 페달·핸들이 다시 버스를 움직임 (0.2.41)
- 먼 전조등 빛무리가 둥글게, 교통 차량의 빛이 차체에서 떨어지지 않음, 힘 반향 휠 복원, 조향 키 고속 동작, 데스크톱 런처의 업데이트 확인·설치 복원, 멀티플레이 참가 시 호스트 맵으로 시작 등 (0.2.39)
- 모드 버스의 3D 미리보기 복원, 노선이 양 끝 정류장 이름으로 표시됨, macOS·Linux 버전 표시, 런처 슬라이더 위치 등 (0.2.38)

## 다운로드

| 플랫폼 | 파일 |
| --- | --- |
| Windows x64 | `openOMSI-<버전>-windows-x64.zip` (`openomsi.exe` 실행) |
| Windows ARM64 | `openOMSI-<버전>-windows-arm64.zip` |
| macOS (Apple silicon / Intel) | `-macos-arm64.zip` / `-macos-x64.zip` |
| Linux x64 / ARM64 | `-linux-x64.zip` / `-linux-arm64.zip` |
| Android (arm64, 8.0+) | `-android-arm64.apk` |
| 전용 서버 | `-server-linux-x64.zip`, `-server-linux-arm64.zip`, `-server-windows-x64.zip`, `-server-windows-arm64.zip` |

> 파일 이름이 `openOMSI-…`로 되어 있는 것은 자동 업데이트가 이 이름 형식으로 파일을 찾기 때문입니다.
