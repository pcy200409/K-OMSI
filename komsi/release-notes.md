**K-OMSI** - [openOMSI](https://github.com/openOMSI-Project/openOMSI) 0.2.30을 바탕으로 K-OMSI 수정을 얹은 빌드입니다.

> **초기 단계 프로젝트입니다. 버그가 있을 수 있습니다.** OMSI 2 정품이 설치되어 있어야 실행됩니다. 이 프로그램에는 게임 콘텐츠가 들어 있지 않습니다.

## K-OMSI에서 더한 것

- **표시 이름**: 창 제목과 업데이트 안내가 K-OMSI로 표시됩니다. 자동 업데이트는 공식 openOMSI가 아니라 이 저장소의 릴리스를 확인합니다.
- **텔레메트리 페달·주행거리**: 텔레메트리의 플레이어 항목에 가속·브레이크·클러치 페달 값(0~1, 운전석과 같이 컨트롤러 입력이 키보드보다 우선)과 버스 총 주행거리(`odometer_km`)를 더했습니다. 외부 채점 도구(DTG / light-taco 등)용입니다.
- **승객 좌석 선택**: 승객이 빈자리를 무작위로 잡지 않고 고릅니다. 짧게 타는 승객은 하차문 근처에 서고, 멀리 가는 승객은 안쪽에 앉으며, 남은 몇 자리는 멀리 가는 승객 몫입니다. 노인(65세 이상)은 빈 좌석이 있으면 앉고 탄 문 가까이 앉습니다. 빈 2인석·창가·사람과 떨어진 입석 자리를 먼저 고릅니다.
- **LAN 차량번호·번호판**: 멀티플레이에서 다른 플레이어의 버스가 그 플레이어 화면과 같은 차량번호와 번호판으로 보입니다.

## openOMSI 0.2.28 ~ 0.2.30 공식 변경사항 (요약)

### 새 기능
- **AI 교통 전면 개편 (0.2.28)**: 프레임과 무관한 20ms 고정 단계, 교차로 진입 순서·출구 공간 예약, 차로 변경 판단 개선, 정류장 정차 위치 순번, 긴급 제동 감소. 긴급차량(`TrafficPriority`)에 길 비켜주기, AI 차량 경적(`ev_AI_Horn`)
- **개발자 도구 (0.2.28)**: Ctrl+Shift+D로 스크립트 변수 보기·고정, 경로·좌석·조명·거울 등 오버레이, 거울 편집기, `.bus`·경로·`sound.cfg`·`model.cfg`·constfile 즉시 다시 읽기
- **퀵 메뉴 (0.2.28)**: OMSI 2처럼 Alt 한 번으로 12칸 메뉴
- **운행 요약 (0.2.28)**: 운행 끝에 정류장별 계획·실제 시각과 주행거리를 복사·저장 (설정 → 게임플레이)
- **시점 편집기 (0.2.28)**: 시점 위치·방향·시야각과 거울을 차량별로 저장
- **행선 입력 양식 (0.2.28)**: 스크립트로 그리는 표시기에 노선번호와 자유 문구 2줄
- **F4 지도 (0.2.28)**: 클릭한 곳으로 차량 이동
- **버스 라디오 (0.2.28)**: 운전석에서 들리는 라디오와 스피커·잡음 효과, 스크립트용 `GetRadioName`/`GetRadioSong`
- **전조등 그림자, `[spotlight_cookie]`, `[led_glow_effect]` (0.2.28)**
- **휴대폰 문 버튼 배치 설정 (0.2.28)**
- **흐린 하늘 표현 (0.2.30)**: 흐린 하늘이 밋밋한 판 대신 구름 덩어리가 있는 어두운 구름층으로 표시 (Enhanced)

### 수정
- 시작 속도 향상과 프레임당 연산 감소, `Velocity`가 구동 바퀴 속도로 바뀜, 운행 선택 시 IBIS·롤러 행선에 자동 입력하지 않음 (0.2.28)
- 사진 모드에서 핸들·페달이 카메라를 움직이지 않음, 투명 유리 뒤 행선판 잔상, 야간 계기판 조명, 정류장 표시기의 행선 문구, 터널 입구 지형 벽, `[matl_alpha]` LED 매트릭스 전체 점등 문제 등 수정 (0.2.28)
- Windows에서 런처가 열리지 않던 문제 수정 (0.2.29). 0.2.28을 설치했다면 런처가 스스로 업데이트할 수 없으니 직접 받아야 합니다
- Omsi.exe가 그리지 않는 스플라인 줄 오브젝트를 그리지 않음, 표면으로 지정된 오브젝트가 멀리서 옆 물체를 뚫고 보이던 문제 수정 (0.2.30)
- 다시 모든 플랫폼용으로 빌드 (0.2.30)

공식 변경 내역 전문(영어): [CHANGELOG](https://github.com/openOMSI-Project/openOMSI/blob/main/CHANGELOG.md)

## 다운로드

| 플랫폼 | 파일 |
| --- | --- |
| Windows x64 | `openOMSI-<버전>-windows-x64.zip` (`openomsi.exe` 실행) |
| Windows ARM64 | `openOMSI-<버전>-windows-arm64.zip` |
| macOS (Apple silicon / Intel) | `-macos-arm64.zip` / `-macos-x64.zip` |
| Linux x64 / ARM64 | `-linux-x64.zip` / `-linux-arm64.zip` |
| Android (arm64, 8.0+) | `-android-arm64.apk` |
| 전용 서버 | `-server-linux-x64.zip`, `-server-linux-arm64.zip`, `-server-windows-x64.zip`, `-server-windows-arm64.zip` |

> 파일 이름이 `openOMSI-…`로 되어 있는 것은 자동 업데이트가 이 이름 형식으로 파일을 찾기 때문입니다.
