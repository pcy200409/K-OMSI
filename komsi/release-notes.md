**K-OMSI** - [openOMSI](https://github.com/openOMSI-Project/openOMSI) 0.2.36을 바탕으로 K-OMSI 수정을 얹은 빌드입니다.

> **초기 단계 프로젝트입니다. 버그가 있을 수 있습니다.** OMSI 2 정품이 설치되어 있어야 실행됩니다. 이 프로그램에는 게임 콘텐츠가 들어 있지 않습니다.

## K-OMSI에서 더한 것

- **표시 이름**: 창 제목과 업데이트 안내가 K-OMSI로 표시됩니다. 자동 업데이트는 공식 openOMSI가 아니라 이 저장소의 릴리스를 확인합니다.
- **텔레메트리 페달·주행거리**: 텔레메트리의 플레이어 항목에 가속·브레이크·클러치 페달 값(0~1, 운전석과 같이 컨트롤러 입력이 키보드보다 우선)과 버스 총 주행거리(`odometer_km`)를 더했습니다. 외부 채점 도구(DTG / light-taco 등)용입니다.
- **승객 좌석 선택**: 승객이 빈자리를 무작위로 잡지 않고 고릅니다. 짧게 타는 승객은 하차문 근처에 서고, 멀리 가는 승객은 안쪽에 앉으며, 남은 몇 자리는 멀리 가는 승객 몫입니다. 노인(65세 이상)은 빈 좌석이 있으면 앉고 탄 문 가까이 앉습니다. 빈 2인석·창가·사람과 떨어진 입석 자리를 먼저 고릅니다.
- **LAN 차량번호·번호판**: 멀티플레이에서 다른 플레이어의 버스가 그 플레이어 화면과 같은 차량번호와 번호판으로 보입니다.


## openOMSI 0.2.31 ~ 0.2.36 공식 변경사항 (요약)

### 0.2.36 (0.2.35는 배포되지 않아 이 버전에 포함)

#### 새 기능
- **새 데스크톱 런처** (Windows·macOS·Linux): 맵 사진, 버스 미리보기, 도색·차량번호·차고, 노선·투어·운행, 시간·날짜·계절·날씨·교통과 멀티플레이를 한 페이지에. 휴대폰용 런처도 추가
- **iPhone·iPad·Mac용 openOMSI** (Xcode로 직접 빌드, docs/APPLE.md)
- **새 인터페이스**: 일시정지 메뉴·내비게이터·도시 지도·시간표 창(Insert) 개편, 새 로딩 화면, 알림 카드, Roboto 대신 Inter 글꼴, 날씨 이름 현지화
- **사진 모드 이동**: W A S D, Space 위, Ctrl 아래, Shift 빠르게

#### 성능
- 장면 스크립트·교통 단계·사람 처리를 프레임 스레드에서 처리 (Spandau 정지 스크립트 4.5ms → 0.24ms, 20~70ms 튀던 프레임 제거), 인구·시간표·사람 채우기 프레임 분산, 먼 신호등 순번 갱신
- 가로등 그림자·거울·연기·하늘·그림자 패스 정리, 타일 일괄 스트리밍
- 프레임 제한 개선, mimalloc, 자동 저장 별도 스레드

#### 수정
- 보행자가 회전교차로 보도를 맴돌지 않음 (#2294), 신호대기 중 버스 뒤 차량이 같이 기다림 (#2293)
- 조명 번짐·큰 텍스처 하얗게 변함·투명 면이 뒤를 가리던 문제 (#2272)
- Enhanced 구름 아랫면과 구름이 튀던 문제, 버스 물리 하위 단계 계산

### 0.2.31 ~ 0.2.34

### 새 기능
- **운행 요약에 평가 추가 (0.2.34)**: 별 5개, 승객 반응 한 줄, 운행 한눈에 보기(정차·정시 정류장, 거리, 시간, 승객)와 운전·승차감·발권 게이지. 버스가 선 5초 뒤에 열립니다
- **런처 시작 버튼 (0.2.34)**: 멀티플레이 서버에 참가하면 "Drive" 대신 참가할 게임 이름이 표시됩니다
- **스스로 복구하는 시작 (0.2.31)**: 런처가 죽거나 2분 안에 그려지지 않으면 새 버전 설치 → 이전 버전 복원 → 안전 모드 순으로 자동 복구. 실패한 버전은 그 컴퓨터에 다시 설치되지 않습니다 (`OMSI_NO_GUARD=1`로 끔)
- **거울 패널 매 프레임 그리기 (0.2.31)**: 설정 → 그래픽의 스위치(기본 꺼짐)
- **AI 교통 개선 (0.2.31)**: 브레이크등 깜박임 제거, 부드러운 제동·커브 감속, AI 경적 소리. 긴급차량은 제한속도의 1.5배(최대 +30km/h)

### 수정
- 버스 신호가 주기 시작에서 멈추던 문제와 빨강·초록이 동시에 켜지던 문제 수정 (0.2.34)
- 빠른 저장(Ctrl+S)을 런처의 이어하기에서 선택할 수 있음 (0.2.34)
- 눈 없는 겨울(종류 4) 텍스처가 맑은 하늘에서 눈 그림으로 보이던 문제, '@' 줄바꿈 텍스트 배치, 맵의 차고 파일 지정 유지, 버스 없이 걸을 때 내비게이터·도시 지도 동작 (0.2.34)
- 단독 철도차량 충돌 수정, 컨트롤러 버튼 페달, 컨트롤러 없을 때 5초마다 멈칫하던 문제, 주차 버스 유지, 사진 모드 시각 복원, 자유 카메라 수평 유지, 수동 변속기 1단 이후 변속, 굴절버스 뒤 차체 높이, 주유소 NL/NG 리프트·경사로 (0.2.33)
- 타임테이블 버스가 세션마다 달라짐, 운전석 카메라별 줌, 햇빛 가리개 동작 (0.2.33)
- 운행 요약이 버스가 설 때까지 기다림, 목적지 표시기 변수 인식, 두 번째 운행 상태 이월 문제, 스플라인 줄 그리기 (0.2.31)

## 다운로드

| 플랫폼 | 파일 |
| --- | --- |
| Windows x64 | `openOMSI-<버전>-windows-x64.zip` (`openomsi.exe` 실행) |
| Windows ARM64 | `openOMSI-<버전>-windows-arm64.zip` |
| macOS (Apple silicon / Intel) | `-macos-arm64.zip` / `-macos-x64.zip` |
| Linux x64 / ARM64 | `-linux-x64.zip` / `-linux-arm64.zip` |
| Android (arm64, 8.0+) | `-android-arm64.apk` |
| 전용 서버 | `-server-linux-x64.zip`, `-server-linux-arm64.zip`, `-server-windows-x64.zip`, `-server-windows-arm64.zip` |

> 파일 이름이 `openOMSI-…`로 되어 있는 것은 자동 업데이트가 이 이름 형식으로 파일을 찾기 때문입니다.
